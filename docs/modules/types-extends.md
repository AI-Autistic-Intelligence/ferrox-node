# Types-Extends Module (`node-yalc/types-extends`)

The `types-extends` module acts as a structural package boundary within the Ferrox-Node monorepo.

Currently, it provides a centralized `tsconfig` compilation target and package definition meant for deep integration with downstream services, but it defers its actual logic exports to the main `@node-yalc/types` module.

It is part of the foundational architectural layer of the YALC dependency tree.
